# KaizenLoom — Story over shots.

> *"We don't chase coverage, we chase meaning. Every project starts with the moment an audience is meant to feel, then works backward to the frames that earn it."*

**KaizenLoom** is a bespoke, cinematic portfolio website for an independent film production studio based between Mumbai and Bhopal. Designed with a dark editorial aesthetic, it showcases documentary series, brand films, music videos, and commercial launch reels with seamless browser interactivity.

---

## ✨ Design & Experience Highlights

- **Cinematic Framing & Atmosphere**: Dynamic live letterboxing, live video background, real-time timecode counter, and grain texture overlays.
- **Scroll-Driven Storytelling**: Text-reveal philosophy section that highlights copy word-by-word as the viewer navigates.
- **Interactive Work Showcase**:
  - Custom-built featured showreel player with scrub bar, duration tracker, and custom audio controls.
  - Interactive project case deck featuring 3D perspective mouse tilt, radial glow tracking, and hover-triggered preview playback.
- **Synthesized UI Audio Engine**: Web Audio API integration generating sound blips on button hovers and toggles.
- **Performance & Accessibility**: Zero dependencies (vanilla JavaScript, CSS3, semantic HTML5), responsive mobile navigation drawer, and full support for `prefers-reduced-motion`.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom properties, CSS Grid/Flexbox, perspective transforms)
- **Typography**: *Instrument Serif* & *Inter* via Google Fonts
- **Interactivity**: Pure JavaScript (Web Audio API, `requestAnimationFrame`, scroll progression)
- **Video Assets**: HTML5 Video with adaptive poster fallbacks
